## Descripción del Proyecto
Sistema de gestión de biblioteca desarrollado en C# orientado a demostrar el uso eficiente y práctico de colecciones genéricas avanzadas:
- **`HashSet<string>`**: Empleado para garantizar la unicidad de los códigos ISBN, previniendo e interceptando registros duplicados de forma eficiente en tiempo de ejecución.
- **`Dictionary<string, List<Libro>>`**: Utilizado para indexar y agrupar las obras literarias por categorías, optimizando las búsquedas y operaciones de recuperación de información.

## Estructura del Repositorio
- `Program.cs`: Código fuente principal que implementa la lógica del gestor, la validación de conjuntos y la manipulación del mapa estructurado.
- `README.md`: Documentación técnica e institucional del proyecto.
